# Smart City Network Simulation & Traffic Analysis

A mini smart city project that combines **Cisco Packet Tracer**, **Python**, and **Flask** to demonstrate secure network communication and traffic congestion monitoring.

## Features
- VLAN-based Smart City Network
- Inter-VLAN Routing (Router-on-a-Stick)
- Traffic, Hospital, School, CCTV, WiFi & Management Departments
- Python Traffic Congestion Analysis
- Flask Web Dashboard

## Technologies
- Cisco Packet Tracer
- Python
- Flask
- HTML/CSS
